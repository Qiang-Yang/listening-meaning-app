# ListenUp - 英语词汇听音练习 Demo

面向初高中生的英语词汇听音练习交互原型，首页包含两个任务：

- `听音辨义`：听发音后直接选择中文释义，支持即时反馈、错题重学和师生报告。
- `听音拼写`：先通过构词模块组合或键盘完整拼写还原英文，再完成中文释义四选一。

第二个任务的原型题库包含 10 个单词：

- 适合构词练习的单词保存为前缀、词根、后缀模块，并在掌握后展示拆解解释。
- 不适合按构词法拆解的单词采用键盘拼写，错误拼写会保留为灰色尝试记录。
- 报告分别统计英文还原首答正确率和中文释义首答正确率。

## 运行

```bash
npm install
npm run dev
```

浏览器使用英文语音合成 API 播放单词，不需要额外音频资源。两个任务的练习进度分别写入浏览器 `localStorage`，不会相互覆盖。

## 在线发布

项目包含 GitHub Pages 自动部署工作流。推送到 `main` 分支后，GitHub Actions 会构建并发布 `dist` 站点。
