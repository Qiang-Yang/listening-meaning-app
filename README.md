# ListenUp - 听音选义学习流程 Demo

面向初高中生的听音选义练习交互原型，覆盖：

- 任务入口、规则准备与试听。
- 逐题听音选义、即时反馈与错题重新掌握。
- 退出恢复、本次完成页、学生学习报告与教师报告。
- 报告内单词专项巩固，并独立记录后续复习，不覆盖原始首答表现。

## 运行

```bash
npm install
npm run dev
```

浏览器使用英文语音合成 API 播放单词，不需要额外音频资源。练习进度写入浏览器 `localStorage`。

## 在线发布

项目包含 GitHub Pages 自动部署工作流。推送到 `main` 分支后，GitHub Actions 会构建并发布 `dist` 站点。
